# Week 1：开发环境与 Python 入门

本周目标：建立开发环境，能写、运行、修改并调试简单 Python 程序。

## 本周验收

- [ ] 能在终端运行 Python 文件。
- [ ] 能解释变量、字符串、数字、布尔值、列表和字典。
- [ ] 能用 `if`、`for`、`while` 解决简单问题。
- [ ] 能用 Git 完成一次提交。
- [ ] 独立写出一个命令行学习记录器。

## Day 1：安装与第一个程序（3 小时）

### 学习

- 安装 Python 3.12+ 与 VS Code。
- 认识终端：`cd`、`dir`、`mkdir`、`python --version`。
- 创建 `src/hello.py`，写入：

```python
name = input("你叫什么名字？")
print(f"你好，{name}！欢迎开始 AI 应用开发。")
```

### 动手

1. 在终端运行 `python src/hello.py`。
2. 修改欢迎语，使其同时显示今天的学习目标。
3. 故意把一个引号删掉，阅读报错后修复。

### 验收

你能不用看教程解释：`input()` 做什么，`print()` 做什么，`f"..."` 为什么能插入变量。

## Day 2：变量、类型与运算（3–4 小时）

学习 `str`、`int`、`float`、`bool`，以及 `+ - * / // %`。写一个程序，输入学习分钟数并换算为小时和分钟。

练习：输入你每天可学习的小时数，计算 24 周内的理论总学习时间。

## Day 3：条件判断（3–4 小时）

学习 `if / elif / else`、比较运算符和逻辑运算符。写“学习状态检查器”：输入当天学习分钟数，输出“未开始 / 达标 / 超额完成”。

## Day 4：循环（3–4 小时）

学习 `for`、`while`、`range()`。写一个程序，依次打印未来 7 天的学习计划，并统计总时长。

## Day 5：列表与字典（3–4 小时）

学习如何保存多个任务及其状态。用一个字典表示一项任务（名称、预计分钟、是否完成），用列表保存一周任务。

## Day 6：小项目与 Git（3–4 小时）

完成“命令行学习记录器”：可以输入学习内容和分钟数，显示当天总时长与完成情况。初始化 Git，并完成第一次提交：

```bash
git add .
git commit -m "完成第一周学习记录器"
```

## Day 7：复盘或休息

完成 `progress.md` 的本周复盘。若前 6 天有未完成内容，优先补齐，不引入新知识。
