# 从零构建 AI 应用（24 周）

面向每天可投入 3–4 小时、没有编程基础的学习者。本课程的目标不是训练大模型，而是学会将模型、知识库、工具与网页界面组合成可上线的 AI 产品。

## 完成后你能做什么

- 使用 Python、Git、命令行和调试工具完成日常开发。
- 构建带网页界面和数据库的 AI 应用。
- 使用大模型 API 实现结构化输出、流式响应与工具调用。
- 构建带来源引用的 RAG 文档知识库。
- 开发可控的 AI 工作流 / Agent，并将项目部署上线。

## 学习方式

- 每周学习 6 天，复盘或休息 1 天；每天 3–4 小时。
- 每天按“概念 → 动手 → 练习 → 记录”的顺序进行。
- 不跳过项目：作品和复盘比看完课程更重要。
